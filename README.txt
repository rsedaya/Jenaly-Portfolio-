Jenaly Raytana - Portfolio Website
==================================
index.html is the whole website (photo, charts and styles are inside it).

Upload to GitHub Pages:
1. Create a new repository on github.com (for example: portfolio).
2. Click "Add file" > "Upload files" and drop index.html into it, then Commit.
3. Go to Settings > Pages. Under "Build and deployment", choose
   Source: Deploy from a branch, Branch: main, Folder: /(root), then Save.
4. After a minute your site is live at https://YOUR-USERNAME.github.io/portfolio/

Vimeo videos: in Vimeo, open each video > Settings > Privacy > Where can this
video be embedded, and allow your github.io address.

To add videos later, edit the VIDEOS list inside index.html (search for "VIDEOS").
